INTRODUCTION TO PROGRAMMING:
============================

PROGRAM:
--------
    It is a set of instructions.

Purpose of using programs:
--------------------------
    1.Reduce Man Power
    2.Fast and Efficiency
    3.Accuracy
    4.Problem Solving
    5.Automatic
    6.Secure

Variable:
--------
    *Variable is a userdefined identifier.
    *Variables is used to storing data in RAM (Temporary Memory).
    *The value change during execution of the program.
    EX: RAM, Pendrive, Memory card 

Constant:
---------
    *The value does not change during execution of the program.
    EX: CD-r, DVD-RAM

Variable naming rules:
----------------------
    1.Must start with alphabet(a-z)
    2.Do not start with number, but we can use second letter onwards
    3.Keyword or reserve words are not allowed
    4.Special characters are not allowed except_
    5.Space not allowed
    6.Varibale name must be unique
