======================================
Three important Components

1.Import required Modules - we use the require directive to load node.js modules.

2.Create Server - A server which will listen to client's request similar to Apache HTTP server.

3.Read request and return response - The server created in an similar step will read the HTTP request made by the client which can be a browser or a console
