Express:
========
 Def : Runtime or Dynamic backend Environment.

 Meaning : To get value from enduser.

 Application : html / react js(form input)

 installation:

 D:\Nisanth\JSD\Express.js>npm install express

 Two Methods:
 =============
 1)get method (default)
 use : it will show all the form input values in URL 
 2)post method
 use : it won't show all the form input values in URL
 (high security - must know about body-parser)

 BODY-PARSER:
 ============
 Hiding form input values in address bar.

Use: It is high security.(do not show password or any form input value in URL)

installation : D:\Nisanth\JSD\Express.js>npm install body-parser

Module import:
===============
